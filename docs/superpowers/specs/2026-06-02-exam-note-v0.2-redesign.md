# 考编笔记 v0.2 — UI 重设计 & 终端修复

> **从 v0.1.0 出发的重设计，不改数据库和 API 层。**

**Goal:** 翻新整体 UI（配色/布局/动效）、修复终端（node-pty WebSocket）、API Key 改为 .env 配置

---

## 1. 配色方案

UI 框架走完全中性路线——内容色已经够丰富，UI 不能抢视觉。

| 层级 | Token | 值 | 用途 |
|------|-------|-----|------|
| 主背景 | `--surface` | `#fafafa` | 页面底色 |
| 次背景 | `--surface-low` | `#f5f5f5` | 侧栏、面板 |
| 高亮 | `--surface-high` | `#ebebeb` | hover 态 |
| 边框 | `--border` | `#e5e5e5` | 分割线 |
| 主文字 | `--on-surface` | `#171717` | 标题正文 |
| 次文字 | `--on-surface-variant` | `#737373` | 辅助说明 |
| **强调色** | `--accent` | `#4f46e5` (indigo-600) | 按钮、选中、链接 |
| 强调-hover | `--accent-hover` | `#4338ca` | hover 加深 |

知识图谱 4 层内容色不变：
- 章节 `#475569` | 知识点 `#0369a1` | 考点 `#a16207` | 真题 `#b91c1c`

```

│ TopBar                                                    │
│ [学科A ▾] [学科B] [学科C] │ [图谱|列表|刷题] │ [+新建] [截图] [AI] [终端] │

│ 章节树      │    知识图谱 (主内容区)      │   AI 对话面板      │
```

- **终端在底部**，可折叠/可拖拽调高

## 3. API Key 配置

- 从 UI 设置面板中**移除 API Key 输入**
- 改为读取环境变量：
  ```env
  AI_API_KEY=sk-xxx
  AI_MODEL=deepseek-chat          # 可选，默认 deepseek-chat
  AI_BASE_URL=https://api.deepseek.com  # 可选
  ```
- AI 设置面板只保留：**模型选择** + **Base URL**（非敏感字段）
- 后端 `/api/ai/chat` 从 `process.env` 读取密钥

## 4. 终端修复

### 4.1 问题
- `window.open('cmd://')` 浏览器不支持该协议 → 空白页
- `fitAddon.fit()` 容器无尺寸时崩溃

### 4.2 方案
- **后端**: WebSocket 服务器 + node-pty 子进程（PowerShell）
- **前端**: xterm.js 通过 WebSocket 连接，ResizeObserver 驱动 fit()
- 终端面板底部展示，可折叠、可拖拽调整高度
- "打开本地 CMD" 按钮改为可选备用方案

### 4.3 实现
- Next.js 自定义 server 或 standalone ws server
- 在 `scripts/start-dev.bat` 中同步启动

## 5. 动画 & 细节

参考 NewGeo 的设计语言：

| 元素 | 规范 |
|------|------|
| 圆角 | 卡片 12px, 按钮 8px, 输入框 8px |
| 阴影 | 卡片: `0 1px 2px rgba(0,0,0,0.04)`; elevated: `0 2px 12px rgba(0,0,0,0.06)` |
| 缓动 | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 动效 | 页面切换 fadeIn 200ms, 面板展开 slideDown 150ms |
| 字体 | Inter + PingFang SC |
| 间距 | 统一 8px 基础单位, 内容区 padding 24px |
| 滚动条 | 6px 宽, 浅灰色, hover 加深 |
